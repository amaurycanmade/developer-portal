About the ROD Portal

The Repository of Observational Data (ROD) is a foundational infrastructure project established by the Franklin Research Hub in 2023. Our mission is to solve the "reproducibility crisis" in computational and behavioral sciences by providing a standardized, highly-available platform for sharing raw and processed observational data.

Our Methodology

We believe data should be as rigorously reviewed as the publications it supports. Every dataset hosted on the ROD Portal undergoes a validation process ensuring:

  • Anonymization: Strict adherence to GDPR and HIPAA protocols for human-subject data.
  • Completeness: Inclusion of all necessary metadata dictionaries and schema definitions.
  • Format Agnosticism: Provision of data in open, non-proprietary formats (e.g., CSV, JSON, Parquet).

API & Integration

Programmatic access to the ROD Portal is available via our REST API. No authentication is required for public datasets, though rate limits apply (1000 requests / hour per IP).

Python Quickstart

You can use the official rod-client library or standard HTTP requests to fetch dataset arrays directly into pandas DataFrames.

# Install the client via pip: # pip install franklin-rod-client import rod_client as rod import pandas as pd # Initialize client (defaults to public endpoint) client = rod.Client() # Fetch dataset by DOI or ID dataset_id = "rod.10.1234/hci-kinematics-26" data = client.get_dataset(dataset_id) # Load specific table into DataFrame df = pd.DataFrame(data.load_table("telemetry_raw.csv")) print(df.head())

Endpoints

  • GET /api/v2/datasets - List all available datasets
  • GET /api/v2/datasets/{id} - Get metadata for a specific dataset
  • GET /api/v2/datasets/{id}/files/{filename} - Download raw data file
